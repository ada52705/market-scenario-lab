# 多指数急跌情景研究与工作台

制作日期：2026-10-11。日行情截至2026-10-09；完整自然月截至2026-09。

本次已覆盖上证综指、沪深300、中证500、中证1000、中证2000、上证50、深证成指、创业板指、中证红利、科创50。主界面默认使用“发布后完整月份”；另可选全历史（含回溯）、近十年（含回溯）、共同发布后区间（2023-09起）。

## 已执行的研究规则

以下规则适用于“自然月急跌”模式，继续保留。新增“滚动窗口回撤”模式使用3、5、10、20、25个交易日窗口和一个月持有期，定义、2015年示例及核验方式见[滚动窗口研究说明](滚动窗口研究说明.md)。两种信号分别计算，不混用。

1. 月收益＝本自然月最后交易日收盘／上自然月最后交易日收盘－1。严格小于－10%、－15%、－20%、－25%分别触发；使用未四舍五入数值。
2. 次月首个交易日开盘买入；从实际买入日期加三个月，在当天或之后的首个交易日开盘卖出。例如2008-11-03买入，2009-02-03卖出。
3. 胜率＝收益严格大于0的完整结局数／全部完整结局数。未到卖出日的事件标为观察中，不进入分母。零收益不算盈利。
4. 每次触发分别作为一个持有事件。持有期可能重叠，跨指数也可能由同一个市场冲击触发；不能把所有指数事件相加当作独立样本。四档是包含关系，跌超25%同时属于其他三档。
5. 最大回撤由买入开盘、卖出前每日收盘、卖出开盘组成的点位路径计算；日内最差收益为持有期最低价／买入开盘－1，两者分母不同。
6. 价格指数，不含股息、滑点、产品费用、跟踪误差。默认交易成本为0，界面可输入单边基点成本，净收益＝卖出／买入×(1－成本)/(1＋成本)－1；回撤仍按未扣费点位。
7. 发布前行情单列为回溯历史。发布当月仅在当月首个交易日已发布时纳入发布后统计。共同发布后区间用于控制各指数历史长度差异。

## 可选持有期

自然月与滚动窗口都支持1个月、3个月、6个月、1年（12个日历月）。默认仍分别为三个月和一个月。变更持有期只改变退出日期与持有路径，不改变信号定义；退出日在实际买入日期加所选月数的当天或之后首个交易日，目标月份无同号日期取该月最后一天。

设置参数后点击“生成结果”，账户与单次事件同步更新。参数修改、恢复默认或矩阵选择不会立即替换已生成结果；未生成期间导出与图表重绘仍使用上一组已生成参数。以下历史表格和原SQLite底稿保留自然月三个月口径，不能当作其他持有期的结果。

## 数据来源与异常处理

- 8个上海/中证系列指数取得指数公司官方日行情；有效官方OHLC优先，其次有效搜狐OHLC，再其次腾讯。深证成指、创业板指主要使用搜狐并以腾讯补齐。
- 官方中证2000接口取得3103条原始数据，基准日2013-12-31仅有收盘价，其后3102条日行情具有OHLC。基准日收盘仅用于月收益分母，不伪造基准日开盘。
- 部分官方查询返回1990-12-01记录，与实际第一条记录的点位重复，日期早于相应指数历史甚至为非交易日，已剔除；原始响应保留。
- 腾讯2015-03-27多指数低价字段异常，已由有效官方/搜狐数据修复。上证综指1992-05-11和1992-06-16仍无法独立修复高低价，保留开盘与收盘并将高低价留空；涉及这些日子的日内最差收益不输出。
- 各指数在2005年以来可比覆盖期间与沪深300交易日期集合核对，未发现缺失交易日。春节长休市间隔不自动视为数据缺失；早期市场日历及点位仍可进一步用授权源复核。
- 缺上月末收盘、相邻月份不连续不计算月收益；未结束月份不触发。官方资料用于核验指数身份、发布日和回溯区间，不等于全部第三方早期日线已获独立验证。

## 已交付的工作台和数据库

- `多指数情景研究工作台.html`：离线可打开，切换指数、跌幅档位、历史范围、起始月份、成本；展示跨指数矩阵、事件明细、持有路径、月收益热图，支持事件CSV导出和客户展示模式。
- `多指数四档急跌情景研究.xlsx`：120组情景汇总、194个跌超10%的基础事件、2614条月度记录、研究口径。月收益和持有收益使用公式；汇总样本数、盈利数、胜率、平均收益由事件公式计算。复杂路径指标由研究引擎计算，附CSV底稿。
- `research.sqlite`：实际已创建本地数据库，包含指数目录、52,804条日行情、月度收益、每月持有队列、跌超10%事件的逐日路径、120组情景汇总、规则和文件哈希。指数与日期组成唯一键。
- `daily.csv`、`monthly.csv`、`events.csv`、`event_paths.csv`、`all_month_cases.csv`、`summary.csv`：可导入其他数据库；原始数据位于`raw/`。
- `ui-validation.json`及预览图片：120组界面结果逐项核对，另检查共同区间、日期筛选、成本、事件切换、无样本、展示模式及手机布局。

当前是固定本地快照，尚未接入自动更新、账号权限或线上发布。正式工作台可复用这套数据表和研究规则，增加授权行情接入、版本化研究任务及客户研究卡片；共享数据库可迁移至PostgreSQL/Supabase，日行情保留长表，不按指数新增宽表列。公开可读数据仍需落实正式对外展示及再分发权限。
