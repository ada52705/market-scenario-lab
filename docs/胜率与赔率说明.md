# 胜率与赔率分析

当前工作台仅使用滚动窗口回撤信号。固定行情截至2026-10-09，非实时数据。

## 两类样本分开

- 单次事件：每次首次穿越分别模拟完整持有期，事件可能重叠；观察中与待买入不进入分母。
- 实际账户交易：只有同一笔资金实际执行并已平仓的交易；因已有持仓而忽略的信号与持仓中交易不进入分母。
- 持仓期间仍识别信号用于事件研究，但账户不加仓，不延长退出日期。

## 指标定义

收益均按当前单边成本计算。盈利指净收益严格大于0，亏损指严格小于0，零收益不算盈利。

| 指标 | 计算方式 |
|---|---|
| 胜率 | 盈利样本数／全部完整样本数 |
| 平均盈利收益率 | 仅盈利样本净收益率的算术平均 |
| 平均亏损收益率 | 仅亏损样本净收益率的算术平均（负数） |
| 赔率（盈亏比） | 平均盈利收益率／平均亏损收益率的绝对值 |
| 平均每次收益 | 全部完整样本净收益率的算术平均，包含零收益 |

赔率是收益率的平均盈亏幅度比，不是总盈利金额／总亏损金额，也不是未来预测概率。没有盈利、没有亏损或没有完整样本时标为“不可估算”，不显示无穷大或人为补0。零收益进入胜率分母，但不影响盈利与亏损均值。

完整样本不足20个时单独提示样本较少。胜率高不代表平均收益必然为正；赔率小于1说明当前样本平均亏损幅度大于平均盈利。事件重叠与跨指数同源冲击意味着样本并非完全独立。

账户交易平均收益率与长期账户复投收益不是同一个指标；未平仓仍计入最新账户净值，但不进入已平仓交易的胜率与赔率。

## 同期指数对照

默认在净值及累计盈亏图展示同一指数的买入持有路径；勾选“不展示同期指数”隐藏曲线与图例，不改变账户执行、样本、导出或分析结果。对照与账户使用相同起始交易日及本金，开盘买入、计入所选买入成本，最新收盘估值，末端不假设卖出。
