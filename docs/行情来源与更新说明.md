## 定期更新可行，但这次不启用

旧fetch_multi_indices.py固定查询日期，已存在文件会复用缓存；analyze_multi_indices.py的ASOF固定为2026-10-11。rebuild_research.py只从已有原始响应重算，当前GitHub Pages工作流也不抓新行情。因此不能把旧脚本直接加一个定时触发就称为实时更新。

后续可以在GitHub Actions收盘后运行、晚间重试，不依赖本机开机，但应先落实：

- 使用动态的北京时间截止日，只接收已完成交易日，不混入盘中日线或休市日占位记录。
- 新增带时间和哈希的原始批次，不覆盖现有原始行情；历史修订单列待核验，不自动改写旧记录。

- 所有指数均校验通过，才生成新的数据版本与回测、运行检查并发布；失败保留上一版。
- 页面显示真实行情截止日、抓取时间、版本和失败或延迟状态，不能承诺“每次访问必定最新”。公开接口的更新时延与可用性不能由本站保证。
- 页面中的截止年月、自然月完成状态和日期标签也应从新版本数据生成，不能继续沿用硬编码日期；研究区间规则的变更需单独版本化，不能默改。

## 持仓估值与整体盈亏

账户持仓中的本笔浮动收益率＝最新收盘持仓市值／买入前账户金额－1；浮动盈亏＝最新持仓市值－本笔买入前金额。按当前成本扣买入费用，不虚构提前卖出，也不扣尚未发生的卖出费用。

整体累计盈亏＝各笔已平仓交易的已实现盈亏之和＋当前持仓浮动盈亏。空仓现金不计息。持仓中净收益字段仍为null，另用unrealized_return、unrealized_pnl、valuation_date、valuation_close表示估值，不进入已平仓胜率与赔率。

独立事件的浮动净收益＝最新收盘／买入开盘／(1＋买入成本)－1；完整事件仍用原买卖两端成本公式。待买入尚未成交，浮动收益留空。估值日期与价格在交易和事件CSV中保留。
