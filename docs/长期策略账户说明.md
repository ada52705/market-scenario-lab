# 长期策略账户回测

本次新增单一资金账户的连续净值、累计盈亏、账户回撤和实际交易记录。原有单次事件研究仍保留，并明确分开显示。

## 执行规则

- 信号仍是自然月收益严格小于所选负阈值，不是从历史高点计算的动态回撤。
- 初始全部为现金。空仓时，次月首个交易日开盘全仓买入，使用允许小数份额的虚拟指数单位。
- 买入日加三个日历月，在当天或之后首个交易日开盘卖出，之后保持现金直到下次信号。
- 已有持仓时忽略新信号，不加仓、不滚动延长持有期；若退出日开盘恰好有新的入场信号，先卖再买。
- 每次退出后资金全部滚动复投；不借款、不做空。空仓现金不计息，价格指数不含股息。
- 成本取工作台单边基点输入。买入单位＝可用现金／买入开盘／(1＋成本)，卖出现金＝单位×卖出开盘×(1－成本)。
- 尚未达到卖出日的实际持仓按最新收盘计入账户盈亏，标为持仓中，不假设提前卖出；它不进入已平仓交易胜率分母。
- 净值路径包含起始开盘、每日收盘、买入后开盘、卖出前开盘和卖出后现金。账户最大回撤相对账户历史净值峰值计算。
- 年化收益使用起止日的全部日历时间，包含空仓；持仓比例使用收盘仍有持仓的交易日数／全部回测交易日数。
- 指数买入持有对照从相同起点开盘买入，计入相同买入成本，末端按收盘估值、不假设卖出。可勾选显示。

工作台可切换10个指数、四档月跌幅、历史范围、起始月份、成本和初始资金；可切换净值/累计盈亏并导出当前选定场景的逐日账户、交易记录。

数据库新增account_summary（全部160组零成本场景）、account_daily与account_trades（默认中证500场景的持久化示例）；其他场景按已有日行情和规则即时重算、可导出。默认逐日账户、交易和全路径CSV也保存在同目录。规则及引擎版本哈希存入research_metadata。
